# roadmap

## 博士修了までの統合ロードマップ

2026年7月から2030年3月までの研究、留学、インターン、就活、住居、資金、生活を一つの時間軸にまとめた個人計画です。

公開ページ: https://aki41105.github.io/roadmap/

## 編集する場所

計画のデータは `src/data.ts`、ページ構成は `src/main.tsx`、見た目は `src/styles.css` にあります。

制度、金額、募集条件、締切は毎年度、公式情報で確認して更新します。

## ローカル確認

```bash
npm install
npm run dev
```

## 公開

`main` ブランチへの更新を GitHub Actions が自動的に GitHub Pages へ公開します。
